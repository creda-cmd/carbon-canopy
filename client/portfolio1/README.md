# Portfolio1

This is a simple personal portfolio scaffold for Faith Musyoka.

## How to use
1. Save your photo as `assets/your-photo.jpg`.
2. Open `index.html` in a browser.
3. Edit the text in `index.html` to personalize the About, Skills, and Experience sections.

## Files
- `index.html` — portfolio page structure
- `styles.css` — visual styling
- `assets/your-photo.jpg` — placeholder path for your image
